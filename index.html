Netlify 部署指南

極速拖曳，無腦發布

推薦新手首選 🌟
1

登入與專案管理

• 登入 Netlify 並進入主畫面。

• 點擊左上角的 Projects (專案)。

2

建立新專案

• 在畫面右上角，點擊青綠色的 Add new project 按鈕。

初次使用此平台者，系統會自動跳過這個步驟，直接進入上傳畫面。
3

上傳網頁檔案

• 在中央第3個區塊 Upload your project files 找到大虛線框。

Drop a project folder...
拖曳檔案至此，或點擊選擇檔案/資料夾

• 若跳出「Rename to index.html?」，強烈建議選擇 Rename and deploy。

4

自訂專屬網址並公開

A

點選 「Make public」 或 編輯(✏️鉛筆圖示)。

B

輸入想要的網址名稱並按 ✅ 確認。

⚠️ 規則：限英文小寫、數字與連字號 -

C

點擊 「Make public」 儲存設定。

大功告成！網站已上線

您的公開網址已立即更新。
點擊產生的連結，就能馬上與世界分享您的作品！

GitHub Pages 部署指南

工程師必備，與版本控制完美結合

開發者常用工具 💻
1
2

登入與建立儲存庫

👉登入 GitHub，進入個人 Dashboard。

Create a new repository

  • 1

    點擊右上角 「+」 圖示，選 「New repository」。

  • 2

    Repository name 必須填寫為：

    你的使用者名稱.github.io

    （例：帳號是 myweb，就填 myweb.github.io）

  • 3

    設定權限選擇 「Public」（必須是公開的）。

  • 4

    點擊下方綠色按鈕 「Create repository」。

3
4

上傳與設定部署

進入 Quick setup，上傳檔案

點擊 「uploading an existing file」 連結。

上傳您的網頁檔案 建議檔名為 index.html。

點擊下方的綠色按鈕 「Commit changes」 完成上傳。

Build and deployment 設定

⚙️ Settings > 📄 Pages

在 Pages 設定頁面中，找到 Build and deployment 區塊。

設定部署來源 (Source) 為 main 分支與 / (root) 根目錄。

儲存後等待數分鐘，即可透過專屬網址造訪。

故障排除注意

若系統提供之專屬網址 看不到網頁內容（顯示 404 等錯誤），最可能的原因是您上傳的主檔名不是 index.html。
解決方案： 此時您可以自行在專屬網址末尾加上檔名來造訪（例如：...github.io/你的檔名.html），或是回 GitHub 將首頁檔案重新命名為 index.html。
